# SDOcraft 1.4.0 — SoloCraft

Лаунчер теперь устанавливает **SoloCraft 0.1.2** с Modrinth: Minecraft 1.20.1, Forge 47.4.16, 111 модов и конфигурации автора. Файлы скачиваются напрямую из исходного пакета и с Modrinth с проверкой контрольных сумм.

Скачайте новый **SDOcraft.exe**, закройте Minecraft и замените прежний EXE. Кнопка на сайте автоматически ведёт на этот выпуск.

- Новая игра: `%APPDATA%/SDOcraft/profiles/solocraft/minecraft`.
- Прежняя сборка остаётся в `%APPDATA%/SDOcraft/minecraft`; её моды и миры не смешиваются с новой.
- Первый запуск загрузит около 414 МБ файлов сборки, затем Minecraft, Forge и Java.
- Обычный запуск сохраняет настройки игрока. «Восстановить» также восстанавливает конфигурации модов; прежние файлы сохраняются в `profiles/solocraft/backups`.
- Русский язык, масштаб интерфейса 2, встроенный адрес сервера, запись в списке серверов и закрытие лаунчера после старта игры сохранены.

**Для подключения на сервере должна стоять совместимая сборка SoloCraft 0.1.2. Обновление лаунчера само по себе не меняет сервер.**

Источник: https://modrinth.com/modpack/solocraft-modpack/version/0.1.2

`modpack.json` оставлен для старых лаунчеров; версия 1.4.0 использует `modpack-solocraft.json`.
