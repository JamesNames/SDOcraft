# SDOcraft 2.0.0 — ChaosZProject

Лаунчер устанавливает **ChaosZProject V2.1.5 Community Edition** из архива владельца на Google Drive: Minecraft 1.20.1, Forge 47.4.6, 285 модов и ресурсы сборки.

Скачайте **SDOcraft.exe**, закройте Minecraft и замените прежний EXE. Нажмите **«Играть»** — сборка, Java и Minecraft установятся автоматически.

- Первая загрузка: архив около 2,17 ГБ, дополнительно Minecraft, Forge и Java. Архив проверяется по SHA-256 и сохраняется для восстановления.
- Новый профиль: `%APPDATA%/SDOcraft/profiles/chaosz/minecraft`. Старые сборки и миры сохранены отдельно.
- Выбор ОЗУ через кнопку в лаунчере; по умолчанию 8 ГБ для новой установки.
- Русский интерфейс, русский язык игры, масштаб 2, встроенный сервер и закрытие лаунчера после старта игры сохранены.
- Сохранено исправление конфликта модулей Forge при запуске.
- Архив не содержит готовой карты. Личные данные CurseForge и старый список серверов из архива не устанавливаются.

**Для подключения сервер должен использовать совместимую сборку ChaosZProject. Лаунчер не меняет сборку на сервере.**

Источник архива: https://drive.google.com/file/d/16SJGytzi1q08fMmYtbwkAET03Oq9Mewj/view

Прежние манифесты сохранены для старых EXE. Этот выпуск использует `modpack-chaosz.json`.
