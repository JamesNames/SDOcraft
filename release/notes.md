Интерфейс SDOcraft теперь на русском языке.

- Добавлен Maxstuff Legacy 1.8.3 hotfix. Файл загружается с официальной страницы автора на Modrinth и проверяется по SHA-256.
- Перед запуском лаунчер устанавливает и проверяет ресурсы Maxstuff в `minecraft/tacz/maxstuff`. Повреждённая папка восстанавливается из JAR; предыдущая копия сохраняется в `mod-backups`.
- Сохранены оформление с фото, иконка SDOcraft и подключение к серверу.

Скачайте только **SDOcraft.exe**, замените старый лаунчер и нажмите **«Играть»**. Если файлы уже установлены, загрузится только новый мод. Игра должна быть закрыта во время обновления.

Для этой версии используются исходные файлы из релиза v1.3.0 — не удаляйте тот релиз.

Пароль — для команды `/login` на сервере. Кнопка «Скопировать /login» копирует команду для вставки в игровой чат.

Установка и восстановление проверены автоматически; отображение предметов и подключение к серверу требуют проверки в Minecraft на ПК игрока.
