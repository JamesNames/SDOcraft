# SDOcraft

Один небольшой `SDOcraft.exe` для Windows. С версии 1.4.0 устанавливает [SoloCraft 0.1.2](https://modrinth.com/modpack/solocraft-modpack/version/0.1.2): Minecraft 1.20.1, Forge 47.4.16, 111 модов и настройки автора. Имя, фото, иконка и русский интерфейс SDOcraft сохранены. В интерфейсе только ник и пароль; адрес `93.119.104.217:25587` закреплён в коде.

## Запуск

Скачать `SDOcraft.exe` из последнего обычного релиза, закрыть Minecraft, заменить старый EXE и нажать **«Играть»**. Сборка скачивается напрямую с Modrinth, около 414 МБ, плюс Minecraft, Forge и Java. Сам EXE моды не содержит. Новый EXE нужно скачать вручную; файлы сборки проверяются при запуске.

**Сервер должен использовать совместимую сборку SoloCraft 0.1.2. Изменение лаунчера не обновляет сервер.**

Новая игра находится в `%APPDATA%/SDOcraft/profiles/solocraft/minecraft`. Прежняя военная сборка, её миры и настройки остаются в `%APPDATA%/SDOcraft/minecraft`. Переносить старые моды в новую папку не нужно.

Перед каждым запуском выставляются русский язык (`lang:ru_ru`) и масштаб интерфейса 2 (`guiScale:2`); остальные настройки игры сохраняются. Лаунчер закрывается после успешного старта процесса Minecraft. Если игра завершается в первые две секунды, окно остаётся открытым и показывает ошибку. «Восстановить» игру не запускает.

SDOcraft сохраняется как видимый сервер в `servers.dat`: после отключения можно снова зайти через **«Сетевая игра → SDOcraft»**. Остальные серверы сохраняются. Предыдущий список копируется в `server-list-backups` внутри папки игры.

Журнал: `game-output.log` или `logs/latest.log` внутри новой папки игры. Фото: `%APPDATA%/SDOcraft/assets`. Ник и память: `%APPDATA%/SDOcraft/settings.json`. Для новой установки по умолчанию выделяется 6 ГБ; ранее сохранённая настройка памяти сохраняется. Значение `ram` можно поменять в JSON при закрытом лаунчере.

## Установка и восстановление

`release/modpack-solocraft.json` закрепляет оригинальный MRPACK, размер, SHA-256, Minecraft и Forge. Лаунчер проверяет архив, читает `modrinth.index.json`, скачивает клиентские файлы с CDN Modrinth с проверкой SHA-512, применяет `overrides` и `client-overrides`. Серверные исключения не устанавливаются. Моды внутри архива также устанавливаются. Все файлы сначала подготавливаются во временной папке; ошибка скачивания не меняет работающую сборку.

Обычный запуск скачивает только отсутствующие и повреждённые моды, сохраняет изменённые настройки модов и `options.txt`. **«Восстановить»** возвращает конфигурации модов к настройкам автора, сохраняя прежние файлы в `profiles/solocraft/backups`; `options.txt` остаётся пользовательским. При обновлении управляемые устаревшие файлы сохраняются в резервную копию. Ошибка применения файлов вызывает откат. Посторонние файлы и миры не удаляются.

Если GitHub временно недоступен, используются сохранённый манифест, оригинальный архив и уже установленные файлы. Загрузка нового архива или модов требует интернета.

## Обновления и публикация

Лаунчер получает `modpack-solocraft.json` из последнего публичного GitHub Release. `modpack.json` оставлен без изменения для старых EXE: они продолжают использовать свою прежнюю сборку. Это предотвращает смешивание сборок. **Не удаляйте v1.3.0:** из него по-прежнему загружается фото и файлы старых клиентов.

Для нового выпуска обновите `VERSION` в `config.py`, `release/modpack-solocraft.json` и `release/notes.md`. Версия манифеста должна равняться `v` + `VERSION`. При смене Minecraft или Forge поменяйте их значения в коде и соберите новый EXE. Адрес и суммы MRPACK берутся из официального проекта автора. Архив и моды не перезаливаются на GitHub.

После успешных Windows-проверок workflow проверяет MRPACK, создаёт черновик релиза с точным коммитом, прикрепляет EXE и оба манифеста, затем публикует релиз. Уже опубликованный выпуск не перезаписывается. Сайт использует `releases/latest/download/SDOcraft.exe` и автоматически предлагает новый EXE.

`tools/prepare_release.py` — прежний инструмент для ручных папок модов формата v1; для SoloCraft он не используется.

## Пароль

Поле пароля предназначено для серверной команды `/login`, не для Microsoft. Нажмите «Скопировать /login» перед запуском, затем в игре откройте чат → Ctrl+V → Enter. Пароль не записывается в файлы лаунчера; команда находится в системном буфере обмена.

## Сборка

Python 3.12 на Windows: запустить `BUILD_EXE.bat`. Результат — `dist/SDOcraft.exe`. Альтернатива: GitHub Actions → Build SDOcraft EXE → Run workflow → артефакт SDOcraft-Windows.

`python -m unittest discover -s tests -v` проверяет загрузки, суммы, изоляцию сборок, защиту путей, слои MRPACK, сохранение настроек, восстановление и откат, запуск отдельного процесса и список серверов. Полный запуск модифицированной игры и подключение проверяются на ПК игрока.

Неофициальный лаунчер, не связан с Mojang, Microsoft или авторами SoloCraft.
