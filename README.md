# SDOcraft

Один небольшой `SDOcraft.exe` для Windows. С версии 2.0.0 устанавливает **ChaosZProject V2.1.5 Community Edition** из архива владельца на Google Drive: Minecraft 1.20.1, Forge 47.4.6, 285 модов, конфигурации и ресурсы. Название, фото, иконка и русский интерфейс SDOcraft сохранены. Адрес `93.119.104.217:25587` закреплён в коде.

## Запуск

Скачайте [SDOcraft.exe](https://github.com/JamesNames/SDOcraft/releases/latest/download/SDOcraft.exe), закройте Minecraft, замените старый EXE и нажмите **«Играть»**. При первой установке загрузится архив около 2,17 ГБ, затем Minecraft, Forge и Java 17. В EXE моды не входят. Понадобится место для архива, распакованной игры и библиотек; желательно не менее 8 ГБ.

Новая игра находится в `%APPDATA%/SDOcraft/profiles/chaosz/minecraft`. Прежние сборки и их миры остаются в своих папках. Старые моды переносить не нужно. Архив не содержит готовой карты.

**На сервере должна стоять совместимая сборка ChaosZProject. Обновление лаунчера само по себе не меняет сервер.**

Для новой установки выделяется 8 ГБ ОЗУ. Кнопка **«ОЗУ для игры»** позволяет выбрать 4, 6, 8, 10, 12 или 16 ГБ. Ранее сохранённое значение учитывается; оставьте память для Windows.

Перед запуском выставляются русский язык и масштаб интерфейса 2. Остальные настройки сохраняются. Лаунчер закрывается, когда процесс Minecraft проработал две секунды. Если игра завершилась раньше, окно остаётся открытым с ошибкой. «Восстановить» игру не запускает.

SDOcraft добавляется в `servers.dat`: после отключения можно снова зайти через **«Сетевая игра → SDOcraft»**. Остальные серверы сохраняются. Журнал находится в `game-output.log` или `logs/latest.log` внутри папки игры.

## Установка и восстановление

`release/modpack-chaosz.json` закрепляет размер и SHA-256 исходного RAR и каждого из 8425 клиентских файлов. Архив загружается с Google Drive с продолжением прерванной загрузки, проверяется и сохраняется в `%APPDATA%/SDOcraft/downloads`. Официальный UnRAR входит в EXE вместе с лицензией.

Устанавливаются `mods`, `config`, `defaultconfigs`, `resourcepacks`, `shaderpacks`, `kubejs`, `tacz`, `data`, `keybinding presets` и начальные настройки игры. Личные данные CurseForge, список серверов из архива, кэши и сохранения не копируются.

Файлы сначала распаковываются во временную папку и проверяются, затем применяются. Обычный запуск исправляет отсутствующие и повреждённые ресурсы и моды, сохраняя пользовательские настройки. **«Восстановить»** также возвращает конфигурации модов к настройкам сборки. `options.txt` остаётся пользовательским. Резервные копии изменённых файлов находятся в `profiles/chaosz/backups`. Ошибка применения вызывает откат; посторонние файлы и миры не удаляются.

Если GitHub недоступен, используется сохранённый или встроенный в EXE манифест. Уже загруженный архив повторно не скачивается. Файл на Google Drive должен оставаться доступным по ссылке; при изменении его содержимого нужны новые контрольные суммы и новый выпуск.

## Обновления и публикация

Лаунчер получает `modpack-chaosz.json` из последнего GitHub Release. `modpack.json` и `modpack-solocraft.json` сохранены для прежних лаунчеров, чтобы разные сборки не смешивались. **Не удаляйте v1.3.0:** из него загружается фото и файлы старых клиентов.

Для нового выпуска обновите `VERSION` в `config.py`, версию и содержимое `release/modpack-chaosz.json`, а также `release/notes.md`. Версия манифеста равна `v` + `VERSION`. При смене Minecraft или Forge нужен новый EXE.

GitHub Actions запускает модульные проверки, скачивает исходный архив, проверяет распаковку на Windows, установку Java и Forge, параметры запуска и расположение элементов интерфейса. Затем собирает EXE и публикует релиз с тремя манифестами. Уже опубликованная версия не перезаписывается. Ссылка `releases/latest/download/SDOcraft.exe` всегда ведёт на последний выпуск. Сам архив на GitHub не перезаливается.

## Пароль

Поле пароля предназначено для серверной команды `/login`, не для Microsoft. Нажмите **«Скопировать /login»** перед запуском, затем в игре откройте чат → Ctrl+V → Enter. Пароль не сохраняется в файлах; команда находится в буфере обмена.

## Сборка

Python 3.12 на Windows: запустите `BUILD_EXE.bat`. Результат — `dist/SDOcraft.exe`. Альтернатива: GitHub Actions → Build SDOcraft EXE → Run workflow → артефакт SDOcraft-Windows.

Тесты: `python -m unittest discover -s tests -v`. Проверка архива и установки Windows: `python tools/verify_windows.py` (использует `RUNNER_TEMP`). Полный запуск игры и подключение к серверу проверяются на ПК игрока.

Неофициальный лаунчер, не связан с Mojang, Microsoft или авторами ChaosZProject.
