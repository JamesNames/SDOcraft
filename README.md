# RoN x TaCZ Riflemen v0.1.0

Forge 1.20.1 addon for Reign of Nether 1.5.0b and TaCZ 1.1.8-hotfix2.

WIP experimental prototype. Riflemans are recruited at village Barracks and equipped with AK-47.

Build with Java 17, Gradle 7.6.5 via `gradle build --no-daemon`.
Install resulting `build/libs/rontacz-riflemen-0.1.0.jar` on both client and server.
